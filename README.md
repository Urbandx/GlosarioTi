# Glosario TI - Aplicación Full-Stack

## Descripción
Aplicación web para consultar términos de Tecnologías de la Información.

## Instalación
Ejecutar `npm install` en backend y frontend.

## Uso
Para iniciar: `npm start` en backend y frontend.

## Tecnologías
- React
- Node.js
- MongoDB

## Características
- Búsqueda de términos
- Filtros por categoría
- Sistema de favoritos
